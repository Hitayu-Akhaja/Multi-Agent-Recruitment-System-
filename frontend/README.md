# Resume Scoring Frontend

Modern React + Vite UI for the Resume Scoring backend.

## Setup

1. Install dependencies:
   - `npm install`
2. (Optional) set API base:
   - Create `.env` with `VITE_API_BASE=http://localhost:8000`

## Run

`npm run dev`

## Notes

- The backend must be running for scoring requests.
- The UI supports JD text or JD file plus resume files or a zip.
